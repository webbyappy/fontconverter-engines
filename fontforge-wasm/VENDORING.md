# VENDORING: third-party sources of ffconv

`ffconv` is GPL-3.0-or-later as a whole. This file lists every third-party source the artifact is built from, its
pin and licence, every local change, and every archive the public source repository (roadmap decision D2) must
carry. Plan: `fontconverter-web/docs/audits/P2-FFCONV-PLAN-2026-11-17.md`, decision P2-10.

## Vendored trees (`vendor/`)

`bash fontforge-wasm/vendor/fetch-vendor.sh` extracted them from the pinned archives; `--check` re-extracts into a
scratch folder, applies `vendor/patches/*.patch` in name order and compares file by file (`VENDOR-CHECK-OK`).
Archives are cached in `build/tarballs/` (not committed) and downloaded only when missing.

## What the public source repository (D2) must carry

This folder (`fontforge-wasm/`, which includes the vendored trees and patches), the GLib tarball above, and the
FreeType 2.13.3 and zlib 1.3.2 port archives; plus the Emscripten version that built the artifact.

Published at `https://github.com/webbyappy/fontconverter-engines` with `font-wasm/` and `harfbuzz-wasm/` (fontconverter-web
P5 plan, P5-13), by fontconverter-web's `scripts/export-engine-source.mjs`. Before that, the build and test scripts lost
their machine-specific defaults: `EMSDK`, `MESON` (build), `FONT_FIXTURES`, `FONTCONVERTER_WEB`, `PLAYWRIGHT_DIR` (tests)
must be set, and `GLIB_TARBALL`, `FREETYPE_ZIP`, `ZLIB_TARBALL` may point at the published archives. `font-wasm/` and
`harfbuzz-wasm/` build into a private Emscripten cache when `EM_CACHE` is set (the zlib port seeded first, as
`deps/seed_ports.py` does here); otherwise they use emsdk's own, frozen.
